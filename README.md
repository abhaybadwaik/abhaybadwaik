## 🛠️ Featured Projects

### 🔹 OCP AI Monitoring Agent
Production-grade OpenShift monitoring agent for a banking client, orchestrated as a **12-node LangGraph StateGraph**.
- 🧠 **LangChain** SSH-based tool execution (Paramiko) + **LlamaIndex** RAG over historical incident logs (BGE-small embeddings)
- 📊 Live **Flask dashboard** with node-level detail modals, alert remediation, and manual cycle triggers
- 🔍 Full **Langfuse** observability across the LLM chain
- ⚙️ Scheduled via APScheduler, containerized with Docker/Podman

### 🔹 CP4I License Assessment & Workload Management System
Enterprise workload/license management platform — owned frontend (8 screens) **and** the GenAI integration layer.
- ⚛️ **React 18 + TypeScript + Tailwind + Vite** frontend with Recharts dashboards
- 🤖 LLM-generated recommendation narratives & consolidated AI summaries powering assessment reports
- 🔗 Integrated with a multi-service **FastAPI/PostgreSQL** backend architecture
